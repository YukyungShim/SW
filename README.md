# NEON WORM // Cyber Survival Arcade (SW_v1)

1988 테트리스 아케이드 스타일의 사이버펑크 네온 UI와 생존 시간(Survival Time) 랭킹 시스템을 탑재한 지렁이(스네이크) 서바이벌 게임입니다.

---

## 🎮 주요 게임 특징

1. **테트리스 아케이드 스타일 3구역 UI 레이아웃**
   - **좌측 패널 (Telemetry & Radar):** 실시간 지렁이 길이, 속도 배율, 사과까지의 거리, 회전 스캔 레이더, 조작 가이드
   - **중앙 패널 (Main Board & HUD):** 실시간 생존 스톱워치(`00:00.00`), 점수 및 사과 개수, 위험 레벨(Hazard Level), 22x22 네온 그리드 보드
   - **우측 패널 (Hall of Survivors):** **살아남은 시간(Survival Time)** 기준 상위 10위 랭킹 리더보드 (로컬 영구 저장 및 초기화 기능)

2. **네온 비주얼 & 파티클 시스템**
   - 사이버네틱 네온 지렁이: 진행 방향을 응시하는 동적 눈동자, 머리에서 꼬리로 이어지는 그라데이션 및 글로우 펄스
   - 네온 사과 (Food): 호흡하듯 리듬감 있게 크기가 변하는 펄스 애니메이션 + 획득 시 20여 개의 네온 스파크 파티클 폭발
   - 보너스 에너지 코어 / 타임 오브 (추가 점수 및 특수 이펙트)
   - 충돌 및 사망 시 화면 흔들림(Screen Shake)과 대형 파티클 폭발 효과

3. **다이내믹 사이버 장애물 (Hazard Barriers)**
   - 레벨 2부터 맵 곳곳에 네온 오렌지 장애물 블록 출현
   - 생성 전 1.6초간 깜빡이는 홀로그램 경고(`!`) 후 완전 고체화되어 플레이어의 급사를 방지
   - 충돌 시 즉시 게임 오버!

4. **지능형 적 사이버 헌터 뱀 (Rogue Hunter AI)**
   - 레벨 3부터 플레이어를 직접 사냥하는 사악한 붉은색 지능형 적 뱀 출현 (레벨 6부터 2마리)
   - 플레이어 위치를 맨해튼 거리 최적화로 실시간 추적하며 사과를 가로채 먹어 몸을 키움
   - 적 뱀에 부딪히거나 적 뱀에게 잡히면 즉시 격추!

5. **생존 시간(Survival Time) 기반 랭킹 시스템**
   - 밀리초 단위 정밀 생존 시간 측정
   - 게임 오버 시 닉네임과 함께 생존 시간(`mm:ss.SS`), 먹은 사과 수, 점수를 랭킹에 등록
   - `LocalStorage`를 활용하여 브라우저를 닫거나 새로고침해도 기록 유지

6. **Web Audio API 자체 내장 사운드 엔진**
   - 별도 외부 오디오 파일 다운로드 없이 100% 브라우저 자체 합성 사운드 재생
   - 8비트 사이버펑크 아르페지에이터 BGM (BGM 토글 가능)
   - 획득/레벨업/사망/경보음(Alert)/헌터 침투음 등에 반응하는 다채로운 효과음 지원

7. **모바일 및 반응형 완벽 지원**
   - 가상 온스크린 터치 D-PAD 제공으로 스마트폰 및 태블릿에서도 쾌적한 플레이 가능

## 🕹️ 조작 방법

| 조작키 | 기능 |
| :--- | :--- |
| `↑` `↓` `←` `→` 또는 `W` `A` `S` `D` | 지렁이 이동 방향 전환 |
| `SPACE` (홀드) | 부스트(일시적 가속 주행) |
| `P` 또는 `ESC` | 게임 일시정지 / 재개 |
| `R` | 즉시 재시작 |
| `ENTER` | 모달 창 확인 / 게임 시작 / 랭킹 등록 |
